# Clippy — Reimagined

A modern revival of the Microsoft Office Assistant ("Clippit", 1997–2003), rebuilt as a
desktop companion that is actually helpful: conversational, context-aware, respectful of
your attention, and fast.

The original Clippy is remembered fondly as a character and poorly as a product. It
interrupted at the wrong moments, understood almost nothing you typed, couldn't do
anything beyond opening help articles, remembered nothing about you, and made Office
noticeably slower on the hardware of its day.

This project keeps the charm and fixes the product. See **[FEATURES.md](FEATURES.md)**
for the full feature plan: every area where the original lagged, the modern feature that
addresses it, and a prioritized roadmap.

## Project status

Early planning. The feature set and roadmap live in [FEATURES.md](FEATURES.md);
implementation has not started yet.

## Guiding principles

1. **Helpful before cute.** The animation is the garnish, not the meal.
2. **Never steal focus.** Clippy suggests; the user decides. Interruptions are earned, not assumed.
3. **Do the thing, don't describe the thing.** Answers come with an "apply it for me" button.
4. **Private by default.** On-device first, explicit consent for anything that leaves the machine.
5. **Fast or absent.** If a feature makes the host app lag, it doesn't ship.
